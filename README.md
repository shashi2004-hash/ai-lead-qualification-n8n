# AI Lead Qualification & First Response

An AI-powered n8n workflow that automatically qualifies incoming leads, generates a personalized first response, logs the lead in a CRM, and routes uncertain cases to human review.

## Workflow

Form Submission
→ Lead Data Processing
→ LLM Qualification
→ Validation
→ CRM Logging
→ Route Based on Decision
→ Auto Reply / Human Review / Discard

## Key Features

- AI-based lead scoring
- Structured JSON output
- Confidence-based safety override
- CRM logging
- Automated email response
- Human-in-the-loop review
- Slack notifications
- Conditional workflow routing

## Tech Stack

- n8n
- LLM API
- Airtable
- Gmail
- Slack
- JavaScript

## Note

Credentials and private configuration have been removed from this public workflow export. Credentials must be configured separately when importing the workflow into n8n.
